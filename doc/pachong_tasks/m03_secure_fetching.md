# M3 抓取与安全访问任务清单

> 模块目标：提供统一、低频、可观测且防 SSRF 的 HTTP 页面和附件读取能力。  
> 前置依赖：无；由 M1 和 M4 调用。  
> 主要目录：`backend/app/announcements/crawler.py`、`backend/app/announcements/security.py`

## 最小可执行任务

- [ ] **M3-T01 增加抓取配置项**：定义连接/读取超时、最大重试、重定向次数、页面/附件大小、单来源并发和请求间隔；添加配置测试。
- [ ] **M3-T02 定义抓取结果与异常类型**：区分超时、DNS、状态码、内容过大、类型不符、安全拒绝和解码失败。
- [ ] **M3-T03 实现允许域名策略**：四个来源仅允许配置的 CUFE 主机及明确附件主机；测试大小写、子域名混淆和尾点域名。
- [ ] **M3-T04 实现危险协议与凭据 URL 拒绝**：只允许 HTTP/HTTPS，拒绝 URL 内嵌用户名密码和非网络协议。
- [ ] **M3-T05 实现解析后 IP 校验**：拒绝环回、私网、链路本地、保留地址和云元数据地址；覆盖 IPv4/IPv6 测试。
- [ ] **M3-T06 实现安全重定向**：限制跳转次数，每跳重新校验协议、域名和解析 IP；添加跨域恶意跳转测试。
- [ ] **M3-T07 实现统一 `httpx.AsyncClient`**：设置 User-Agent、超时和连接池，按来源复用客户端并在 Worker 停止时关闭。
- [ ] **M3-T08 实现有限退避重试**：仅对瞬时网络错误和指定 5xx 重试，不对 4xx、安全拒绝和内容过大重试。
- [ ] **M3-T09 实现每来源限速器**：限制并发和相邻请求间隔；使用模拟时钟验证不会突发请求。
- [ ] **M3-T10 实现流式大小限制**：页面和附件在下载过程中超过上限立即终止，不依赖 `Content-Length` 可信。
- [ ] **M3-T11 实现响应类型与编码处理**：基于头部、文件签名和页面声明识别 HTML/附件类型，支持常见中文编码回退。
- [ ] **M3-T12 实现安全临时下载接口**：创建任务隔离临时文件，返回受控路径和元数据，失败时自动删除半成品。
- [ ] **M3-T13 添加本地模拟服务器集成测试**：覆盖超时、重试、重定向、乱码、分块超大响应和连接中断。
- [ ] **M3-T14 添加安全回归测试**：验证 DNS/IP 绕过、危险 URL、重定向逃逸和伪造 MIME 均被阻止。

## 完成条件

- [ ] M1、M4 不自行创建未受控 HTTP 客户端。
- [ ] 所有外部访问均经过协议、域名、IP、重定向和大小检查。
- [ ] 单个请求失败返回结构化错误，不泄露密钥或完整内部堆栈。
