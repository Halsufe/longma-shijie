# M4 正文与附件解析任务清单

> 模块目标：安全提取网页正文及支持附件的文本，使用 CPU OCR 处理图片和扫描 PDF，并保证失败可降级、临时文件可清理。  
> 前置依赖：M3 安全下载；M7 附件实体用于持久化状态。  
> 主要目录：`backend/app/announcements/extractors.py`、`backend/app/services/announcement_attachment_service.py`

## 最小可执行任务

- [ ] **M4-T01 定义标准解析结果**：包含文本、页码、解析状态、媒体类型、错误摘要和是否使用 OCR；添加 Schema 测试。
- [ ] **M4-T02 实现 HTML 正文清洗**：去除脚本、样式、导航、页脚和重复空白，保留段落及表格文本；添加中文样本测试。
- [ ] **M4-T03 复用文本 PDF 解析**：封装现有 `pypdf` 能力，输出逐页文本和页数；添加多页与空页测试。
- [ ] **M4-T04 实现扫描 PDF 判定**：文本层为空或低于阈值时进入页面渲染与 OCR；避免对已有有效文本重复 OCR。
- [ ] **M4-T05 实现 PDF 页面渲染**：在页数、分辨率和总像素上限内生成临时图片；超限返回部分解析状态。
- [ ] **M4-T06 集成 PaddleOCR CPU 中文模型**：提供延迟初始化和单例复用，输出按阅读顺序合并的文本；添加图片固件测试。
- [ ] **M4-T07 实现 JPG/JPEG/PNG OCR**：校验真实图片格式和尺寸，处理旋转方向，超限时安全失败。
- [ ] **M4-T08 复用 DOCX 文本解析**：封装 `docx2txt`，处理空文档和损坏文档；添加固件测试。
- [ ] **M4-T09 实现 DOC 转换沙箱**：使用 LibreOffice headless、独立临时目录和进程超时转换为 DOCX，不执行宏。
- [ ] **M4-T10 实现不支持附件降级**：Excel、压缩包、音视频只记录名称、类型、链接和 `unsupported` 状态。
- [ ] **M4-T11 实现解析资源上限**：配置单文件大小、PDF 页数、OCR 时长、Office 转换时长和 CPU 并发信号量。
- [ ] **M4-T12 实现附件逐个失败隔离**：一个附件失败不阻断其他附件和正文，公告聚合状态正确变为 `partial`。
- [ ] **M4-T13 实现临时文件生命周期**：每个附件在 `finally` 中删除，Worker 启动及 M11 再清理超时残留。
- [ ] **M4-T14 增加 Worker 专用依赖清单**：固定 PaddleOCR CPU、PDF 渲染、图片和 HTML 解析依赖版本。
- [ ] **M4-T15 更新 Dockerfile**：安装 LibreOffice headless、中文字体及必要系统库，OCR 模型在构建或部署阶段准备。
- [ ] **M4-T16 添加端到端解析测试**：覆盖正文、文本 PDF、扫描 PDF、DOCX、DOC、图片、不支持类型、损坏文件和超时。

## 完成条件

- [ ] 所有规定附件类型均有成功样本和失败样本测试。
- [ ] 原始附件不进入长期存储，任务结束后无临时文件残留。
- [ ] OCR/Office 失败不会阻断公告形成最小可推送记录。
