# M1 来源配置与适配器任务清单

> 模块目标：将四个通知网站的列表页和详情页转换为统一候选公告与标准文档，不包含网络重试、数据库写入、相关性判断和摘要生成。  
> 前置依赖：M3 抓取客户端接口；M7 来源实体仅用于集成。  
> 主要目录：`backend/app/announcements/adapters/`、`backend/tests/fixtures/announcements/`

## 最小可执行任务

- [ ] **M1-T01 定义适配器输入输出协议**：创建 `AnnouncementCandidate`、`AnnouncementDocument`、`AttachmentLink`、`CrawlContext` 数据结构及 `AnnouncementSourceAdapter` Protocol；为必填字段和日期格式添加测试。
- [ ] **M1-T02 实现 URL 规范化工具**：支持相对地址补全、片段移除、主机名小写和默认端口归一化；用参数化测试覆盖四站链接样例。
- [ ] **M1-T03 建立适配器注册表**：按 `adapter_key` 注册和获取适配器，未知键返回明确异常；添加注册表单元测试。
- [ ] **M1-T04 保存中财主站离线样本**：准备通知列表、分页和详情 HTML 固件，样本脱离网络即可运行测试。
- [ ] **M1-T05 实现中财主站列表解析**：提取完整标题、官网发布日期和详情 URL，兼容置顶及非日期排序；通过离线样本测试。
- [ ] **M1-T06 实现中财主站详情解析**：提取正文、附件名称及链接，排除导航和页脚；通过离线样本测试。
- [ ] **M1-T07 保存中财大青年离线样本**：准备 `tzgg.htm` 列表、分页和详情 HTML 固件。
- [ ] **M1-T08 实现中财大青年适配器**：完成列表、分页、日期、详情正文和附件解析；通过离线样本测试。
- [ ] **M1-T09 保存管工学院离线样本**：准备 `tzgg.htm` 列表、分页和详情 HTML 固件。
- [ ] **M1-T10 实现管工学院适配器**：完成列表、分页、日期、详情正文和附件解析；通过离线样本测试。
- [ ] **M1-T11 保存教务处离线样本**：准备 `tzgg.htm` 列表、分页和详情 HTML 固件，覆盖首页 `MM/DD` 与详情完整日期差异。
- [ ] **M1-T12 实现教务处适配器**：以详情页日期为权威值，完成列表、分页、正文和附件解析；通过离线样本测试。
- [ ] **M1-T13 实现 30 天候选扫描停止条件**：遇到连续过期且已知候选时停止翻页，但仍检查置顶 URL；添加乱序、置顶和跨页测试。
- [ ] **M1-T14 实现单条解析失败隔离**：缺少标题、日期或 URL 时返回结构化失败，不中断同页其他候选；添加坏数据样本测试。
- [ ] **M1-T15 完成四适配器契约测试**：用同一测试套件验证字段完整性、URL 合法性、日期类型、分页终止和详情输出。

## 完成条件

- [ ] 四个适配器全部通过离线契约测试，测试过程不访问真实官网。
- [ ] 任一站点样本损坏不会使其他适配器测试失败。
- [ ] 适配器不直接访问 Repository、通知中心或 AI 服务。
