# M9 公告查询与工作台任务清单

> 模块目标：向登录用户提供最近 30 天公告查询，并在工作台增加可筛选的学校公告区域和通知深链接。  
> 前置依赖：M7 公告数据、M8 汇总快照。  
> 主要目录：`backend/app/api/routes/school_announcements.py`、`frontend/js/views/overview.js`、`frontend/js/views/notifications.js`

## 最小可执行任务

- [ ] **M9-T01 定义用户响应 Schema**：公告列表项、分页响应、来源选项和汇总快照；内部错误、AI 置信度和解析文本不外泄。
- [ ] **M9-T02 实现公告列表 Repository 查询**：按可见性和 30 天保留期过滤，默认按首次发现/关键更新时间倒序。
- [ ] **M9-T03 实现关键词筛选**：匹配标题、摘要和待办事项；对空关键词和特殊字符安全处理。
- [ ] **M9-T04 实现来源筛选**：合并公告匹配任一来源即可返回，并在响应中保留全部来源。
- [ ] **M9-T05 实现日期筛选**：支持官网发布日期和首次发现日期两种明确口径，限制查询范围。
- [ ] **M9-T06 实现 `GET /school-announcements`**：接入认证、分页、组合筛选和统一错误处理。
- [ ] **M9-T07 实现 `GET /school-announcements/sources`**：返回启用来源及显示顺序。
- [ ] **M9-T08 实现汇总可见性校验**：用户仅能读取已为其创建投递记录的指定汇总快照。
- [ ] **M9-T09 实现 `GET /school-announcement-digests/{id}`**：返回不可变快照，包括空汇总。
- [ ] **M9-T10 注册路由和 OpenAPI 测试**：加入 `main.py`，验证认证、分页上限和错误码。
- [ ] **M9-T11 扩展前端路由参数解析**：支持 `#overview?announcement_digest_id=<id>`，不破坏现有纯 hash 路由。
- [ ] **M9-T12 创建公告前端 API 加载器**：公告请求与工作台其他请求独立，支持取消过时筛选请求。
- [ ] **M9-T13 实现工作台公告区域骨架**：增加全宽区域、标题、汇总头、加载、空和错误状态。
- [ ] **M9-T14 实现公告筛选控件**：关键词输入、来源菜单、日期口径和日期范围，保持稳定布局。
- [ ] **M9-T15 实现公告条目渲染**：展示标题、来源、官网日期、摘要和有值的结构化字段。
- [ ] **M9-T16 实现状态与链接**：展示已更新、多来源、部分附件失败；原文和附件新窗口安全打开。
- [ ] **M9-T17 实现分页或加载更多**：筛选状态不丢失，动态内容不引起布局跳动。
- [ ] **M9-T18 适配通知中心深链接**：识别公告汇总通知，携带 `ref_id` 导航并滚动到公告区域。
- [ ] **M9-T19 实现深链接失败降级**：汇总不存在时显示局部错误并继续展示最近公告，不影响其他工作台面板。
- [ ] **M9-T20 添加后端契约测试**：覆盖权限、筛选、过期数据、汇总可见性和链接字段。
- [ ] **M9-T21 添加前端契约与浏览器测试**：覆盖桌面/移动端、长标题、空字段、筛选、分页和深链接。

## 完成条件

- [ ] 用户可在工作台查询最近 30 天公告并组合筛选。
- [ ] 可选字段缺失时对应 UI 直接隐藏，无“未说明”占位。
- [ ] 公告区域故障不会破坏现有工作台和通知中心功能。
