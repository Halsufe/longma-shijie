# M10 管理运维与告警任务清单

> 模块目标：提供任务可观测、人工任务创建、失败处理、分级站内告警和审计能力。  
> 前置依赖：M2 任务执行、M7 数据访问、M8 通知投递。  
> 主要目录：`backend/app/api/routes/admin_announcements.py`、`backend/app/services/announcement_alert_service.py`、`frontend/js/views/admin.js`

## 最小可执行任务

- [ ] **M10-T01 定义管理响应 Schema**：任务列表、任务详情、来源健康、统计和错误摘要；隐藏内部密钥及完整堆栈。
- [ ] **M10-T02 实现任务列表查询**：支持任务类型、状态、来源、触发方式和日期分页筛选。
- [ ] **M10-T03 实现任务详情查询**：返回窗口、耗时、数量、连续失败、重试链和安全错误摘要。
- [ ] **M10-T04 实现来源健康汇总**：提供最后尝试/成功时间、连续失败次数及当前启用状态。
- [ ] **M10-T05 实现单来源手动抓取 API**：只创建 `pending` 任务，返回 `202 + task_id`，不在请求线程抓取。
- [ ] **M10-T06 实现失败任务重试 API**：校验可重试状态，创建带 `retry_of_id` 的新任务，拒绝重复运行冲突。
- [ ] **M10-T07 实现单公告重解析 API**：公告存在且未过期时创建任务，复用正常解析管线。
- [ ] **M10-T08 实现单公告重摘要 API**：创建任务并复用 M6，不直接发送已结束窗口通知。
- [ ] **M10-T09 为管理接口接入管理员权限**：普通用户全部返回权限错误；添加角色测试。
- [ ] **M10-T10 接入审计日志**：记录管理员、动作、目标 ID、任务 ID 和结果，不记录附件正文。
- [ ] **M10-T11 定义严重告警事件**：整体任务失败、汇总失败、调度异常和关键依赖故障映射为立即告警。
- [ ] **M10-T12 实现严重告警幂等**：恢复数据库连接后向所有 active 管理员发送一次，不重复刷屏。
- [ ] **M10-T13 实现单项问题聚合器**：按日期汇总单站、正文、附件、OCR 和 AI 降级问题。
- [ ] **M10-T14 实现晚间管理员通知**：每个日期至多一条普通异常汇总，突出连续失败来源。
- [ ] **M10-T15 实现数据库不可用日志降级**：无法写站内通知时记录结构化严重日志，恢复后补发告警。
- [ ] **M10-T16 实现管理后台概览**：展示最近轮询、最近汇总、失败来源和当日降级数量。
- [ ] **M10-T17 实现任务表与筛选**：提供状态、类型、来源、时间列和任务详情入口。
- [ ] **M10-T18 实现人工操作按钮**：重抓、重试、重解析和重摘要提交后展示任务 ID 并轮询状态。
- [ ] **M10-T19 添加 API 权限与幂等测试**：覆盖未登录、非管理员、重复提交、冲突和不存在目标。
- [ ] **M10-T20 添加告警集成测试**：覆盖严重即时、单项晚间、连续失败升级、数据库恢复和管理员状态过滤。
- [ ] **M10-T21 添加管理前端测试**：覆盖空状态、失败详情裁剪、按钮状态和移动端布局。

## 完成条件

- [ ] 管理员无需访问服务器即可定位来源或处理阶段失败。
- [ ] 所有人工操作异步执行、可追踪且不会生成重复用户通知。
- [ ] 严重告警与晚间异常汇总的时机、接收人和幂等均通过测试。
