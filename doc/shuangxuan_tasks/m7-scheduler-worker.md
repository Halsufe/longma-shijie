# M7 调度 Worker 任务清单

> 来源：`../shuangxuan_proposal.md` 第 4、12、15 章；`../shuangxuan_high-level-design.md` 第 4.7、10.3、11.3 章  
> 目标：用独立 Worker 完成阶段推进、提醒、自动计算/发布、停机补偿和失败重试。  
> 依赖：M1、M6、M8。

## 最小可执行任务

### 调度数据与租约

- [ ] M7-T01 新增 `MentorSelectionTaskRun` 模型，包含 task key、类型、轮次、状态、租约、重试次数和错误摘要。
- [ ] M7-T02 为 `task_key` 增加唯一约束，为到期任务扫描增加状态/租约索引。
- [ ] M7-T03 创建并验证任务运行表 Alembic 迁移 upgrade/downgrade。
- [ ] M7-T04 实现稳定 task key 生成规则，键中包含批次、轮次、任务类型和业务截止时间版本。
- [ ] M7-T05 实现任务领取和租约接管：有效租约跳过、过期租约允许其他 Worker 接管。

### 到期扫描与执行

- [ ] M7-T06 实现 `DueTaskScanner`，识别学生阶段开始/截止、导师截止、提前 24 小时提醒、计算和发布时间。
- [ ] M7-T07 实现主选学生截止处理：锁定志愿并推进到导师选择阶段。
- [ ] M7-T08 实现导师截止处理：选取最后有效名单、调用 M6 计算并进入待发布状态。
- [ ] M7-T09 实现主选发布时间处理：发布主选结果并按配置开放补录。
- [ ] M7-T10 实现补录截止处理：全部匹配进入待发布，否则进入 blocked 并触发管理员通知。
- [ ] M7-T11 实现补录发布时间处理：只有 M6 守卫通过才发布并完成批次。
- [ ] M7-T12 实现失败重试和恢复扫描，服务恢复后立即处理所有已到期未成功任务。

### 进程、配置与验证

- [ ] M7-T13 新增 `mentor_selection_worker.py`，支持默认 60 秒循环和 `--once` 单次执行。
- [ ] M7-T14 新增 Worker 配置项并在部署文档/Compose 中加入独立进程启动方式。
- [ ] M7-T15 添加阶段边界、停机恢复、重复扫描、失败重试和 blocked 延长后恢复测试。
- [ ] M7-T16 添加双 Worker 同时领取同一 task key 的并发测试，断言只产生一次业务结果。

## 模块完成定义

- [ ] M7-DO1 Web 进程不承担双选定时循环，Worker 停机不导致状态丢失。
- [ ] M7-DO2 自动任务可重试且不会重复计算、发布或通知。
- [ ] M7-DO3 `--once` 测试、Worker 专项测试和静态检查通过。
