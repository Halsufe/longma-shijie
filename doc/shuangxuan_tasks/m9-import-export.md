# M9 导入导出任务清单

> 来源：`../shuangxuan_proposal.md` 第 8.2、8.5、10.1、15 章；`../shuangxuan_high-level-design.md` 第 4.9、10.2 章  
> 目标：支持 CSV、XLSX、XLS 学生名单预检/确认和管理员多数据集导出。  
> 依赖：M2 名单服务、M6 结果服务、现有文件上传和确认令牌能力。

## 最小可执行任务

### 依赖与解析

- [ ] M9-T01 在依赖清单加入 `openpyxl`、`xlrd`、`xlwt`，记录分别负责 XLSX 读写、XLS 读取和 XLS 写出。
- [ ] M9-T02 实现 CSV 解析器，支持中文/英文表头映射并返回统一的行号、学号、姓名、班级结构。
- [ ] M9-T03 实现 XLSX 解析器，读取单元格值但不执行公式或外部链接。
- [ ] M9-T04 实现 XLS 解析器，输出与 CSV/XLSX 相同的标准化行结构。
- [ ] M9-T05 实现表头、空行、重复行、扩展名/文件头、大小和最大行数校验，错误包含原始行号。

### 预检与确认

- [ ] M9-T06 实现导入预检服务，调用 M2 资格校验并返回总数、可导入数、重复数、错误数和逐行结果。
- [ ] M9-T07 生成绑定文件 SHA-256、批次 ID、操作者和行摘要的确认令牌，预检不写入参与表。
- [ ] M9-T08 实现确认导入：重新解析上传文件、校验令牌和摘要、存在任何错误时整批拒绝、成功时单事务调用 M2 写入。
- [ ] M9-T09 新增 `/students/import/preview` 和 `/students/import/confirm` 管理员接口，三种格式使用同一响应结构。

### 导出

- [ ] M9-T10 实现统一导出查询，支持参与学生、参与导师/名额、完整志愿/理由、导师决定、主选/补录/最终结果、未匹配列表数据集。
- [ ] M9-T11 实现 CSV 导出并防止以 `= + - @` 开头的单元格触发表格公式。
- [ ] M9-T12 实现 XLSX 导出，设置稳定表头、日期格式和工作表名称，不写公式。
- [ ] M9-T13 实现 XLS 导出，处理旧格式行列限制并在超限时返回明确错误或要求改用 CSV/XLSX。
- [ ] M9-T14 新增管理员导出接口，使用 `dataset` 和 `format` 白名单参数并接入 M8 导出审计。

### 验证

- [ ] M9-T15 添加三种格式正常导入、错误表头、学号不存在、姓名不一致、重复学号、令牌文件不一致测试。
- [ ] M9-T16 添加三种格式各数据集导出、权限拒绝、公式注入转义、超限保护和导出审计测试。

## 模块完成定义

- [ ] M9-DO1 CSV/XLSX/XLS 使用相同业务校验，错误文件不产生部分导入。
- [ ] M9-DO2 所有导出仅管理员可用且来自有效快照/结果版本。
- [ ] M9-DO3 M9 专项测试、依赖安装验证和静态检查通过。
