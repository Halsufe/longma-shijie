# M4 学生志愿任务清单

> 来源：`../shuangxuan_proposal.md` 第 5、9.4、10.2 章；`../shuangxuan_high-level-design.md` 第 4.4、5.4、6.2 章  
> 目标：实现主选/补录志愿版本、草稿、正式提交、撤回、重提和截止锁定。  
> 依赖：M1、M2、M3。

## 最小可执行任务

### 数据与迁移

- [ ] M4-T01 新增 `MentorPreferenceSubmission` 模型，保存批次、学生、轮次、版本、个人陈述、状态和提交/撤回时间。
- [ ] M4-T02 新增 `MentorPreferenceItem` 模型，保存导师、连续排名和针对该导师的理由。
- [ ] M4-T03 增加版本联合唯一、同版本导师唯一和排名唯一约束及查询索引。
- [ ] M4-T04 创建并验证志愿表 Alembic 迁移 upgrade/downgrade。

### 校验与服务

- [ ] M4-T05 定义志愿草稿、正式提交、详情和列表 Schema，接口不接受客户端指定版本号之外的持久状态。
- [ ] M4-T06 实现主选校验：3-4 位批次导师、导师不重复、排名从 1 连续、个人陈述和每位导师理由必填。
- [ ] M4-T07 实现补录校验：至少 1 位有剩余名额的导师、不设最多数量、排名连续、陈述和理由必填。
- [ ] M4-T08 实现草稿保存，每次保存生成新版本或安全更新当前草稿，且不要求满足正式提交条件。
- [ ] M4-T09 实现正式提交，在事务中执行阶段、参与资格、档案完整性和志愿规则校验，并将当前版本设为唯一有效提交。
- [ ] M4-T10 实现截止前撤回，不物理删除历史版本；撤回后允许重新提交新版本。
- [ ] M4-T11 实现截止锁定服务，Worker 可把最后有效正式提交标记为 locked；未提交草稿不参与导师候选。
- [ ] M4-T12 实现补录复制主选内容为草稿，复制后仍需学生重新确认和正式提交。

### 接口与验证

- [ ] M4-T13 新增本人志愿查询、保存草稿、正式提交、撤回接口，校验只能操作本人。
- [ ] M4-T14 新增学生导师列表接口中的正式申请人数统计，明确不统计草稿和撤回版本。
- [ ] M4-T15 添加主选/补录数量、重复导师、缺少理由、保存草稿、撤回重提、截止锁定和并发版本测试。

## 模块完成定义

- [ ] M4-DO1 每次状态变化都有可追溯版本，当前有效正式提交唯一。
- [ ] M4-DO2 截止后所有学生写接口由后端拒绝。
- [ ] M4-DO3 M4 专项测试、静态检查通过。
