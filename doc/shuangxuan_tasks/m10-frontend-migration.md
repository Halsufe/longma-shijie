# M10 前端与兼容迁移任务清单

> 来源：`../shuangxuan_proposal.md` 第 11、14、17 章；`../shuangxuan_high-level-design.md` 第 4.10、8、10.4 章  
> 目标：交付学生、导师、管理员三端界面，替代旧交流申请并完成安全迁移。  
> 依赖：M1-M9。后端接口稳定后开始端到端联调。

## 最小可执行任务

### 共享前端基础

- [ ] M10-T01 新增 `mentor_selection_common.js`，集中维护阶段标签、状态徽标、错误码中文映射、时间显示和倒计时。
- [ ] M10-T02 新增 `mentor_selection.js` 入口，按当前用户角色和 `/current` 响应加载学生/导师视图。
- [ ] M10-T03 所有写请求携带当前版本和 `Idempotency-Key`；版本冲突时重新加载并明确提示。
- [ ] M10-T04 前端不以浏览器时间决定权限，按钮状态只作提示，最终以 API 阶段响应为准。

### 学生端

- [ ] M10-T05 实现批次状态、截止时间、提交状态和倒计时区域。
- [ ] M10-T06 实现导师列表和研究方向/院系筛选，展示申请人数、剩余名额及需求规定的导师字段。
- [ ] M10-T07 实现 3-4 个主选志愿的添加、删除和上下排序，禁止重复导师。
- [ ] M10-T08 实现补录至少 1 个且不设上限的志愿编辑，只展示有剩余名额导师。
- [ ] M10-T09 实现统一个人陈述和逐导师理由输入，以及保存草稿、正式提交、撤回重提交互。
- [ ] M10-T10 扩展个人资料页面，支持手机号、邮箱和任意课程成绩的新增、编辑、删除，少于 3 门时显示提交前提示。
- [ ] M10-T11 实现主选结果、补录入口和最终结果视图，学生只能查看本人结果。

### 导师端

- [ ] M10-T12 实现选择自己的候选学生列表、已接收/待处理/剩余名额统计。
- [ ] M10-T13 实现授权档案详情，展示联系方式、简介、陈述、给本导师理由、课程成绩、已审核成果和证明附件。
- [ ] M10-T14 实现接收/拒绝、保存名单和最终提交，4 人上限/补录剩余上限有即时提示。
- [ ] M10-T15 结果发布后只展示最终匹配学生，前端不缓存或继续展示失效候选档案。

### 管理端

- [ ] M10-T16 实现批次列表、创建/编辑、阶段时间配置、状态和提交率仪表。
- [ ] M10-T17 实现 CSV/XLSX/XLS 选择、预检明细、错误阻止确认和确认导入交互。
- [ ] M10-T18 实现教师库勾选、最少 3 人提示和参与导师列表。
- [ ] M10-T19 实现只读汇总、名额使用、未匹配列表、延长、重开和撤回结果确认弹窗。
- [ ] M10-T20 实现数据集/格式选择和管理员导出按钮，错误信息可读且不暴露服务端路径。
