# 前端浏览器验收记录

日期：2026-08-07

本地 URL：`http://127.0.0.1:8000/`（验收后服务已停止）

## 视口

- 320 x 800
- 375 x 812
- 768 x 900
- 1024 x 900
- 1440 x 900

以上视口均检查页面级横向溢出；登录页登录按钮在移动首屏可见，工作台统计网格按 1/2/4 列响应。

## 场景

- 登录页品牌、院徽自然尺寸与 `object-fit: contain`。
- 管理员登录与工作台真实数据加载。
- 移动侧栏打开、遮罩、Esc 关闭、背景滚动锁定、焦点返回。
- AI 对话消息滚动、底部输入区、移动会话抽屉。
- 知识库面包屑和表格容器内部滚动。
- 课程与作业课程筛选。
- 通知、成果与社区、教师与计划、党建、个人设置路由冒烟。
- 管理后台 tabs、统计卡和 1024px 布局。
- 成果与社区「我的成果」在全部年份、单一年份下固定展示八大类别；每类实时统计数量，新增成果加载后定位并高亮对应类别。
- 用户头像、知识库文件图标和成果列表图标容器在 1024px、375px、320px 下保持固定尺寸并数学居中；窄屏无页面级横向溢出。
- 当前版本资源无新增浏览器 console error。
