# M7 前端动态表单模块（Dynamic Form）

> 输入文档：`../achievements_proposal.md`（第 5、6、10.3 章）、`../high-level-design.md`（4.7、8）  
> 前置依赖：M1 模板注册表、M2 接口、M3 附件接口  
> 完成定义：按分类渲染模板表单，附件与校验完整，新增与编辑回显全流程可用。

## 任务清单

- [x] T7-1 动态表单渲染
  - 交付物：`frontend/js/achievement_form.js`，分类选择后按模板渲染字段；控件映射：是/否用单选或开关、枚举用下拉、年份/月份用数字、URL 校验输入、长文本用多行输入、人名列表用文本框加提示。
  - 验收：8 类表单正确渲染，模板标题文案使用需求文档原文。
- [x] T7-2 前端校验
  - 交付物：必填（“无”“forthcoming”视为已填）、年份 4 位、月份 1-12、经费两位小数或“无”、URL、页码、人名列表逗号分隔校验。
  - 验收：错误提示定位到具体字段，阻止提交。
- [x] T7-3 附件组件
  - 交付物：`frontend/js/achievement_upload.js`，位于表单顶部，支持多份、预览、删除、替换，至少 1 份提示。
  - 验收：与 M3 接口联动，提交前附件状态正确。
- [x] T7-4 提交与编辑回显
  - 交付物：新增提交 POST、编辑回显 PUT；旧数据无 `details` 时回退通用字段并提示补全必填。
  - 验收：新增与编辑全流程可用，回显字段与保存参数一致。
- [x] T7-5 前端测试
  - 交付物：8 类渲染、校验拦截、附件联动、回显测试。
  - 验收：全部通过。
