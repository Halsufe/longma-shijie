# F07 AI 对话前端任务

> 依赖：F02、F05
> 影响文件：`frontend/js/views/chat.js`、必要时 `styles.css`
> 目标：优化会话列表、消息区和输入区的层级及移动端会话抽屉。

## 最小任务

- [x] 保留桌面端会话侧栏 + 消息区结构和现有会话切换逻辑。
- [x] 区分用户消息、AI 消息、引用/附件、生成中和错误状态。
- [x] 输入区固定在底部，发送按钮正确呈现禁用、发送中、失败状态。
- [x] 长文本、Markdown、代码块和附件不撑破消息容器，消息区独立滚动。
- [x] 移动端隐藏会话侧栏，提供抽屉入口，抽屉关闭后消息区恢复全宽。
- [x] 保留重新生成、复制、停止生成、模型/知识库选择等现有操作语义。

## 验收

- [ ] 发送、切换会话、刷新、错误重试和附件展示不回归。
