# F17 党建管理子模块前端任务

> 依赖：F05、F15
> 影响文件：`frontend/js/admin_party.js`、必要时 `styles.css`
> 集成方：`admin.js`
> 目标：统一党员档案、政治面貌审核、名册、学习资料、活动和党建统计的管理布局。

## 最小任务

- [x] 保留党员档案、政治面貌审核、政治面貌名册、学习资料、活动管理和党建统计子视图。
- [x] 每个子视图使用统一标题区 + toolbar + panel/table 组合。
- [x] 筛选器在桌面端保持同排或合理换行，移动端上下堆叠。
- [x] 统计卡复用共享 stats-grid；表格复用 data-table 和内部滚动容器。
- [x] 新增/编辑、阶段流转、材料上传、活动状态推进和删除继续使用现有确认/弹窗流程。
- [x] 危险操作使用危险按钮和二次确认；状态 badge 同时输出文字。
- [x] 保留 CSV 导入/导出、材料下载、审核和活动归档的 API、权限和状态转换。

## 验收

- [ ] 管理后台可正常切换党建子 tab，返回后筛选状态和页面事件不重复。
- [ ] 管理员在 768px 和 375px 下可以完成筛选、查看、编辑和确认操作。
- [ ] 非管理员无法加载或操作本模块。
