# F02 应用壳层与登录前端任务

> 依赖：F01、F03、F05
> 影响文件：`frontend/js/app.js`、必要时 `frontend/assets/styles.css`
> 目标：实现统一的登录页、侧栏、顶部栏、角色导航和移动端抽屉。

## 最小任务

- [x] 更新登录页品牌锁定：院徽、`龙马·视界`、`中央财经大学管理科学与工程学院`、简短欢迎语。
- [x] 删除登录页虚构统计数字，保留学号/工号、密码、显示密码、登录、首次改密流程。
- [x] 更新侧栏品牌锁定和学院短名，保留用户、角色和退出入口。
- [x] 保持 `ROUTES` key、角色过滤和管理员入口逻辑不变，仅修正文案和视觉钩子。
- [x] 保留顶部当前路由标题、日期、通知入口；统一导航点击后的 route 切换。
- [x] 小于 860px 时侧栏抽屉化，菜单按钮、scrim、关闭和导航后自动收起可用。
- [x] 抽屉打开时锁定 body 滚动，支持 scrim 和 Esc 关闭，关闭后焦点回到菜单按钮。
- [x] view 切换前执行现有 cleanup，避免重复监听。

## 验收

- [ ] 未登录显示登录页，登录成功和失败行为与改版前一致。
- [ ] 学生、教师、校友、管理员各自看到的导航项与改版前一致。
- [ ] 桌面端保持左侧导航 + 顶部栏 + 内容区；移动端无页面横向滚动。

## 非目标

- [ ] 不改变 token、用户接口、路由名称和权限判定。
