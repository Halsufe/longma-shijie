# F04 接口适配与静态资源访问前端任务

> 依赖：F01
> 影响文件：`frontend/js/api.js`、必要时 `frontend/assets/` 引用
> 目标：为视觉改版提供稳定的请求、错误和下载边界。

## 最小任务

- [x] 核对所有页面请求均通过 `api()`、`qs()`、`download()`，不新增裸 `fetch`。
- [x] 确认 JSON、multipart、文件下载三类请求的认证头和错误转换不变。
- [x] 确认静态资源基础路径仍为 `/static`，院徽引用不混入 API 路径。
- [ ] 为图片/字体加载失败提供可视化降级，不吞掉业务请求错误。
- [x] 核对 API 错误可被 `toast`、表单字段或局部状态面板正确展示。

## 验收

- [x] 登录、通知、工作台、聊天、知识库、课程、成果、党建和管理请求参数未改变。
- [x] 文件预览/下载仍走原有权限和文件名处理。
- [ ] 401/403/5xx 在页面上有可读提示，控制台没有未处理 Promise rejection。

## 非目标

- [x] 不新增后端接口或改变响应字段。
