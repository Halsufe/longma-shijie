# F06 工作台前端任务

> 依赖：F02、F05
> 影响文件：`frontend/js/views/overview.js`、必要时 `styles.css`
> 目标：按确认优先级重排工作台首屏，不改变统计接口和跳转语义。

## 最小任务

- [x] 保留欢迎语、当前身份和主操作，统一使用 `pageHeader()`。
- [x] 第一行展示真实成果/课程作业/计划/通知统计，窄屏降为 2/1 列。
- [x] 主列展示成果统计或近期成果、今日安排和待办。
- [x] 辅助列展示快捷入口、AI 对话入口、党建动态和通知。
- [x] 所有 `[data-go]` 跳转继续调用 `context.navigate()`，不改 route key。
- [x] 每个异步区块支持 loading、局部 error 和 empty 状态，禁止虚构占位数字。
- [x] 管理员系统概览继续按角色显示，不让普通用户看到管理统计。

## 验收

- [x] 首屏顺序为成果统计、快捷入口、党建动态、AI 对话入口、待办、通知。
