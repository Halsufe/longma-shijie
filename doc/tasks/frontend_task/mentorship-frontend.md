# F11 教师与计划前端任务

> 依赖：F05
> 影响文件：`frontend/js/views/mentorship.js`、必要时 `styles.css`
> 目标：优化教师/导师信息、匹配申请和个人计划的扫描效率。

## 最小任务

- [x] 教师条目统一显示头像、姓名、研究方向和可操作入口。
- [x] 计划使用时间线或分组列表，突出下一步行动、完成状态和截止/提醒时间。
- [x] 筛选、匹配、申请、接受、拒绝、取消和删除继续复用现有 API 与确认逻辑。
- [x] 空数据、加载和失败场景使用共享状态组件。
- [x] 移动端教师信息和计划操作按上下顺序排列，按钮不被挤压。

## 验收

- [ ] 教师匹配与计划勾选/删除/状态流转不回归。
- [ ] 研究方向和计划表单使用统一 field/modal 样式。
