# F12 党建前台前端任务

> 依赖：F05
> 影响文件：`frontend/js/views/party.js`、必要时 `styles.css`
> 目标：在品牌深蓝基础上引入少量红色语义点缀，优化党建活动、政治面貌和学习资料布局。

## 最小任务

- [x] 将政治面貌状态、活动筛选、活动列表和学习资料拆成清晰面板。
- [x] 活动条目突出标题、类别、时间、地点、报名/签到状态和详情入口。
- [x] 保留政治面貌申请、活动报名、签到、附件下载和详情弹窗。
- [x] 红色仅用于党务语义或重要状态，不使用整页大红背景。
- [x] 复用 badge、toolbar、modal、toast 和状态面板。
- [x] 按现有角色权限显示学生/管理员可用操作。

## 验收

- [ ] 学生页面和管理员页面的权限边界不变。
- [ ] 活动、政治面貌和资料加载失败时可局部提示，其他区块仍可用。
