# F08 知识库前端任务

> 依赖：F05
> 影响文件：`frontend/js/views/knowledge.js`、必要时 `styles.css`
> 目标：统一知识库作用域、文件夹、工具栏、列表和预览布局。

## 最小任务

- [x] 顶部统一放置个人/班级作用域切换、搜索、上传和新建操作。
- [x] 显示当前文件夹面包屑和筛选状态，切换作用域时避免无提示跳转。
- [x] 文件夹和文件使用清晰的行类型区分，文件类型、大小、更新时间和操作列对齐。
- [x] 预览、下载、移动、删除按钮使用共享 icon/button 和 tooltip。
- [x] 预览弹窗在手机端全屏化；空、加载、无权限和上传失败使用共享状态面板。
- [x] 保留现有文件权限、上传配额、预览和下载接口。

## 验收

- [ ] 列表只在自身容器内横向滚动，不造成页面级横向滚动。
- [ ] 个人与班级知识库的可见操作与原角色规则一致。
