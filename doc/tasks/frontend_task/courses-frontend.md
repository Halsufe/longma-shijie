# F09 课程与作业前端任务

> 依赖：F05
> 影响文件：`frontend/js/views/courses.js`、必要时 `styles.css`
> 目标：统一课程筛选、作业状态、附件和提交相关布局。

## 最小任务

- [x] 将课程筛选和作业列表组织到统一 toolbar，移动端上下堆叠。
- [x] 作业行优先显示课程名、标题、截止时间、提交状态和附件入口。
- [x] 逾期、待提交、已提交等状态使用共享 badge 语义色并同时显示文字。
- [x] 作业详情、附件预览、上传和提交弹窗复用共享 modal/field 样式。
- [x] 保留附件上传、预览、下载、多版本提交和权限行为。
- [x] 为空、加载、失败和无权限场景提供共享状态反馈。

## 验收

- [ ] 教师发布、学生提交、附件预览/下载的原流程可完成。
- [ ] 手机端操作按钮可点击且不被长标题挤出容器。
