# M10 管理配置与运营模块任务清单

> 模块目标：提供角色默认额度、用户额度调整、审计记录和班级用量运营界面。
> 前置依赖：M7 额度服务、M8 统计服务、管理员认证与班级管理范围。
> 主要目录：`backend/app/api/routes/admin*`、`frontend/js/views/admin.js`、配置 schema 和审计服务。

## 最小可执行任务

- [ ] **M10-T01 定义管理员额度配置 schema**：角色限定为管理员、教师、学生；校验非负、上限和必填原因规则。
- [ ] **M10-T02 实现角色额度查询接口**：返回当前策略、版本、生效时间和更新时间，仅管理员可访问。
- [ ] **M10-T03 实现角色额度更新接口**：保存新策略和配置版本，立即影响后续请求，不回溯历史用量。
- [ ] **M10-T04 实现用户额度覆盖接口**：按用户设置临时额度/有效期，校验管理员对目标用户的管理范围。
- [ ] **M10-T05 实现额度调整审计查询**：按用户、操作者、日期查询前后值、原因和生效时间。
- [ ] **M10-T06 实现管理端额度页面**：展示三类角色额度、保存状态、校验失败和生效提示。
- [ ] **M10-T07 实现用户额度调整页面**：按班级筛选用户，输入额度和原因，展示当前有效额度。
- [ ] **M10-T08 接入班级用量统计页面**：支持按班级筛选、多班级汇总、用户明细、状态和待对账量。
- [ ] **M10-T09 禁止修改模型配置**：隐藏/禁用原有管理端 AI 模型选择，或将该功能改为固定 DeepSeek V4 Flash 展示。
- [ ] **M10-T10 编写管理员权限测试**：普通用户拒绝所有管理接口，管理员跨管理范围调整/查询被拒绝。
- [ ] **M10-T11 编写配置生效测试**：修改额度后后续请求立即使用新额度，历史 usage 和报表不被重算。

## 完成条件

- [ ] 管理员可以配置三类角色默认额度并调整指定用户额度。
- [ ] 所有调整都有完整审计，且越权目标不可操作。
- [ ] 管理员可查看管理范围内班级统计，不能修改模型为其他模型。
