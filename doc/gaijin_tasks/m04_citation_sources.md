# M4 引用来源模块任务清单

> 模块目标：将知识库文档和联网网页来源统一持久化、校验并返回给前端。
> 前置依赖：M1 消息模型、M2 范围守卫、M3 统一检索结果。
> 主要目录：`backend/app/models/`、`backend/app/schemas/`、`backend/app/services/`、Alembic 迁移。

## 最小可执行任务

- [ ] **M4-T01 建立来源类型枚举**：只允许 `knowledge` 和 `web`，并定义来源缺省字段规则。
- [ ] **M4-T02 创建 `chat_message_citations` 模型**：实现消息关联、来源类型、知识库/文档、URL、片段、排序和时间字段。
- [ ] **M4-T03 增加数据库索引和约束**：为 `message_id/rank`、来源类型和文档查询建立索引，完成迁移与回滚测试。
- [ ] **M4-T04 实现知识库来源归一化**：从 RAG 结果提取知识库名称、文档名称和命中片段，保留来源 scope。
- [ ] **M4-T05 实现网页来源归一化**：保存标题、URL、摘要和排序，校验 URL 格式并脱敏不安全字段。
- [ ] **M4-T06 实现范围一致性校验**：个人回答不得保存班级引用，none 消息不得保存知识库引用，引用消息必须属于当前会话。
- [ ] **M4-T07 扩展消息查询响应**：历史消息返回按 rank 排序的引用，并区分知识库/网页来源类型。
- [ ] **M4-T08 实现引用幂等写入**：同一消息、来源和排序重复事件不会创建重复记录。
- [ ] **M4-T09 增加引用审计日志字段**：保存实际 scope、用户、班级和来源类型，支持安全排查。
- [ ] **M4-T10 编写来源测试**：覆盖两类来源展示、跨范围拒绝、重复事件、历史加载和 URL 异常。

## 完成条件

- [ ] 每条带来源回答都能从消息 ID 追溯到引用记录。
- [ ] 前端可以明确区分知识库文档引用和联网网页引用。
- [ ] 任何跨用户、跨班级或 none 模式的非法引用都被服务端拒绝。
