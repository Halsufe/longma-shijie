# M3 RAG 检索与联网回退任务清单

> 模块目标：按唯一授权范围检索知识库；无结果时先提示，再通过供应商无关的联网适配器回退。
> 前置依赖：M2 范围守卫、现有 `ChatRetrievalService`、`RAGService`。
> 主要目录：`backend/app/services/chat_retrieval_service.py`、`backend/app/ai/retriever.py`、新增联网适配器目录。

## 最小可执行任务

- [ ] **M3-T01 定义统一检索结果结构**：包含 `knowledge_status`、`hit_count`、上下文片段、scope 和标准化来源元数据。
- [ ] **M3-T02 实现 `retrieve(context, query)`**：只使用 M2 输出的授权 context，不接受未校验的 scope/user/class 参数。
- [ ] **M3-T03 实现 none 快速路径**：`scope=none` 直接返回 `skipped`，不得初始化或调用 RAG 客户端。
- [ ] **M3-T04 实现个人/班级检索路径**：将授权 scope、用户 ID 和班级 ID 传给现有 RAG 服务，保留命中顺序和片段。
- [ ] **M3-T05 实现无结果判定**：`hit_count=0` 返回 `not_found`，区分检索失败和确实无匹配。
- [ ] **M3-T06 增加未找到事件**：在联网回退前生成稳定的 `knowledge.not_found` 事件和前端可展示文案。
- [ ] **M3-T07 定义 `WebSearchAdapter` 协议**：实现 `search(query, user_id, class_id, timeout)` 返回标题、链接、摘要、时间和错误状态。
- [ ] **M3-T08 注入联网适配器**：按联网开关和运行时策略决定是否回退；供应商配置通过适配器隔离。
- [ ] **M3-T09 实现联网成功路径**：将网页结果转换为标记为 `web` 的上下文和来源，不混入知识库来源。
- [ ] **M3-T10 实现联网失败路径**：返回 `WEB_SEARCH_UNAVAILABLE` 或等效状态，不伪造知识库命中或模型来源。
- [ ] **M3-T11 增加检索超时和取消**：RAG/联网分别受超时控制，超时错误不会触发跨知识库切换。
- [ ] **M3-T12 编写单元与集成测试**：覆盖命中、无结果、none、不允许联网、联网成功、联网超时和供应商异常。

## 完成条件

- [ ] 知识库无结果时顺序固定为“未找到资料”事件 → 联网搜索。
- [ ] 不同知识库范围不会互相回退或共享上下文缓存。
- [ ] 联网来源与知识库来源可以被下游引用模块明确区分。
- [ ] 无联网服务或联网失败时状态可追踪且无虚假来源。
