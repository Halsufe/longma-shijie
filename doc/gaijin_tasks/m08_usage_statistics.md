# M8 用量统计模块任务清单

> 模块目标：提供用户个人用量和管理员按管理范围的班级筛选、汇总、明细查询。
> 前置依赖：M7 已结算用量和额度审计、现有班级/管理员权限。
> 主要目录：新增 `chat_usage_service.py`、`backend/app/api/routes/`、统计 schema 和测试。

## 最小可执行任务

- [ ] **M8-T01 定义统计查询参数**：支持日期、班级、用户、模型、状态、分页和汇总/明细模式，统一北京时间边界。
- [ ] **M8-T02 实现个人今日用量接口**：返回已用、额度、剩余、重置时间、输入/输出/总量和待对账量。
- [ ] **M8-T03 实现个人历史接口**：按日期和会话聚合已结算 usage，区分失败重试和待对账数据。
- [ ] **M8-T04 解析管理员管理范围**：先得到可管理班级集合，再得到成员集合，禁止客户端直接传全量用户条件绕过权限。
- [ ] **M8-T05 实现班级汇总接口**：支持单班级筛选、多班级汇总、总量、用户数、请求数和待对账量。
- [ ] **M8-T06 实现管理员明细接口**：按用户、日期、模型、状态查看 usage events 和额度调整记录。
- [ ] **M8-T07 增加统计口径说明字段**：响应标识已结算、待对账和重试用量，避免前端把请求次数当 Token。
- [ ] **M8-T08 增加索引和分页限制**：为日期、班级、用户和状态建立查询索引，限制最大页大小。
- [ ] **M8-T09 编写权限测试**：普通用户只能查本人；管理员只能查管理班级；跨范围和篡改参数均拒绝。
- [ ] **M8-T10 编写统计一致性测试**：核对 usage event、每日汇总、重试和额度调整后的统计结果。

## 完成条件

- [ ] 用户可以查看当日额度、剩余和重置时间。
- [ ] 管理员可按多个班级筛选/汇总且不能越权。
- [ ] 统计只使用已结算数据，待对账单独展示，结果可与 usage 明细对账。
