# M5 LLM 对话编排模块任务清单

> 模块目标：复用现有 LLM 适配器、SSE、超时和错误处理，固定使用 DeepSeek V4 Flash。
> 前置依赖：M1-M4、现有 `ChatService`、LLM 适配器和聊天路由。
> 主要目录：`backend/app/services/chat_service.py`、`backend/app/api/routes/chat.py`、LLM 配置模块。

## 最小可执行任务

- [ ] **M5-T01 盘点现有 LLM 调用链**：记录模型配置入口、SSE 事件、超时、错误转换和 usage 返回结构，确定扩展点。
- [ ] **M5-T02 固定 DeepSeek V4 Flash 模型常量**：建立受保护服务端配置，统一内部模型标识和供应商实际名称映射。
- [ ] **M5-T03 禁止用户选择其他模型**：移除普通用户模型选择字段；请求传入其他模型时忽略或返回 `MODEL_NOT_ALLOWED`。
- [ ] **M5-T04 固定编排顺序**：实现范围校验 → 额度预留 → 检索/回退 → 请求记录 → LLM → 持久化 → usage 结算。
- [ ] **M5-T05 创建逻辑请求记录**：记录 request ID、幂等键、模型、scope、开始时间和当前状态。
- [ ] **M5-T06 扩展 SSE 事件封装**：所有事件携带 request ID、事件序号和状态，新增 accepted/delta/completed/failed 等事件。
- [ ] **M5-T07 持久化流式增量内容**：每个安全增量定期或按事件序号保存，完成时写入最终内容和 usage。
- [ ] **M5-T08 复用现有错误和超时机制**：将模型错误转换为稳定业务错误码，不重复实现供应商级错误解析。
- [ ] **M5-T09 接入引用事件**：模型回答关联 M4 来源，发送 `citation.added` 或等效事件。
- [ ] **M5-T10 处理取消和会话锁**：用户取消或会话并发冲突时停止生成、保存状态并释放资源。
- [ ] **M5-T11 编写编排集成测试**：模拟命中、无结果联网、none、模型成功、超时、5xx、取消和固定模型校验。

## 完成条件

- [ ] 所有普通用户请求只能调用 DeepSeek V4 Flash。
- [ ] SSE 事件可以关联到唯一逻辑请求并支持最终状态恢复。
- [ ] 失败、取消和成功请求均持久化状态，不丢失已生成内容和 usage 信息。
- [ ] 编排器不直接访问知识库索引，只消费 M3 的已授权上下文。
