# M1 会话与消息持久化任务清单

> 模块目标：让 AI 会话具备稳定 ID、完整历史、知识库模式记录、可恢复状态和严格的会话访问权限。
> 前置依赖：现有 `ChatSession`、`ChatMessage`、`ChatRepository`、认证与数据库。
> 主要目录：`backend/app/models/chat.py`、`backend/app/repositories/chat_repo.py`、`backend/app/api/routes/chat.py`、Alembic 迁移。

## 最小可执行任务

- [ ] **M1-T01 盘点现有会话字段和接口**：记录现有会话/消息字段、状态、路由和前端依赖，形成兼容字段表；不得直接删除旧字段。
- [ ] **M1-T02 增加会话默认模式字段**：为 `chat_sessions` 增加 `knowledge_scope`、`web_search_enabled` 和必要的更新时间字段，默认值只允许 `personal/class/none` 中的一个。
- [ ] **M1-T03 增加消息请求字段**：为 `chat_messages` 增加实际模式、逻辑 `request_id`、状态、错误码、错误信息和完成时间字段。
- [ ] **M1-T04 增加中断恢复字段**：增加部分输出内容和最后 SSE 事件序号字段，支持流式中断后的状态查询。
- [ ] **M1-T05 建立状态枚举和转换校验**：实现 `pending/generating/retrying/completed/failed/cancelled/quota_exceeded/interrupted` 状态白名单，拒绝非法状态跳转。
- [ ] **M1-T06 扩展会话创建与更新接口**：支持保存默认知识库模式和联网开关，服务端校验模式，不信任客户端用户 ID 或班级 ID。
- [ ] **M1-T07 扩展历史消息响应**：返回每条消息的实际模式、请求状态、错误信息、部分输出和引用入口，保持旧客户端可解析。
- [ ] **M1-T08 加固会话链接权限**：所有会话、消息和附件读取继续按当前用户过滤；新增测试覆盖猜测会话 ID、停用用户和无权班级成员。
- [ ] **M1-T09 实现会话级并发保护**：同一会话已有生成请求时拒绝或取消新请求，返回稳定的 `REQUEST_IN_PROGRESS` 错误码。
- [ ] **M1-T10 添加数据迁移和回滚验证**：完成 Alembic upgrade/downgrade，验证旧会话可读取，新字段为空时有兼容默认行为。
- [ ] **M1-T11 编写模块集成测试**：覆盖刷新/重登后的历史恢复、消息顺序、模式持久化、状态更新和越权拒绝。

## 完成条件

- [ ] 会话链接在刷新、重新登录和多端打开时能恢复同一用户的完整历史。
- [ ] 每条新消息保存实际知识库模式和请求状态，非法模式和非法状态跳转被拒绝。
- [ ] 任意越权会话、消息或受限班级引用读取均被服务端拒绝。
- [ ] 迁移可在 SQLite/PostgreSQL 上执行，现有聊天回归测试通过。
